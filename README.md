## Featured Work

### [SecureLaunch AI](https://github.com/eniolad223/securelaunch-ai)

An AI security case study exploring how an organization can reduce sensitive data exposure before content is sent to an external AI provider.

I translated security policy into a working Python control gateway, tested allow, mask, and block decisions, and independently validated selected controls with Amazon Bedrock Guardrails.

**Evidence:** 43 automated security checks, 15 synthetic gateway scenarios, and 9 of 9 selected AWS Guardrail scenarios matching expectations.

**Tools and methods:** Python, Amazon Bedrock Guardrails, Streamlit, pytest, GitHub Actions, threat modeling, and risk analysis.
